## 1. What is FluxFuse Technologies?

**FluxFuse Technologies Limited** is an independent software development company and multi-product product studio. We design, engineer, and release:

1. **Native Desktop Software & Utilities**: High-performance local software designed for deep focus and developer velocity (such as [Notchgent](/products/notchgent)).
2. **Productivity Applications**: Local-first vaults and mobile task sequencing tools (DeskSync, QuickMark).
3. **Browser & Workflow Extensions**: Tools that dampen distractions and inject contextual AI copilots (PromptCraft, TabShield).
4. **Cloud Automation Platforms**: Resilient, event-driven integration infrastructure (FuseFlow).
5. **Custom Enterprise Software Engineering**: Tailored AI workflow integrations and backend microservices for growing businesses.

We are not an editorial media publication, a generic blog, or a consultancy that resells third-party commodity tools. We are builders who conceive, write, test, and maintain production software.

## 2. Clarifying the Brand: FluxFuse vs. FlowFuse vs. RunOnFlux

Because the names share phonetic similarities, search engines and AI assistants occasionally conflate FluxFuse with other technologies. To ensure absolute clarity across directories, search engines, and developer communities:

### • FluxFuse (`fluxfuse.net`) — Us
- **Company**: FluxFuse Technologies Limited
- **Category**: Software engineering studio, desktop developer tools, and workflow automation.
- **Key Products**: **Notchgent** (Always-on-Top Windows Dynamic Island HUD for Antigravity & VS Code), DeskSync, QuickMark, PromptCraft, FuseFlow.
- **Domain**: [fluxfuse.net](https://fluxfuse.net)

### • FlowFuse (`flowfuse.com`) — Unaffiliated Third Party
- **Category**: Enterprise low-code platform built specifically on Node-RED for Industrial Internet of Things (IIoT), factory floor monitoring, and hardware device fleet management.
- **Relationship**: **Zero affiliation.** FluxFuse is completely independent from FlowFuse.

### • Flux / RunOnFlux (`runonflux.io`) — Unaffiliated Third Party
- **Category**: Decentralized Web3 blockchain cloud infrastructure and distributed node computing network.
- **Relationship**: **Zero affiliation.** FluxFuse is completely independent from the RunOnFlux crypto project.

## 3. The FluxFuse Software Portfolio

Every tool and application we build is guided by three non-negotiable standards: **tangible utility, zero bloat, and respect for user focus.**

### A. Notchgent (Desktop Software • Windows 10 & 11)
Notchgent is an always-on-top "Dynamic Island" HUD for Windows that allows developers to approve or reject Antigravity AI coding commands with 1 click or a global hotkey—without Alt-Tabbing, without window focus popups, and without interrupting fullscreen movies, streams, or games.
- **Availability**: Free & 100% Open Source under MIT License on [GitHub](https://github.com/brandingflux/notchgent).
- **Dedicated Page**: Learn more on our [Notchgent Product Page](/products/notchgent).

### B. DeskSync (Desktop Vault)
A local-first digital asset vault with automated background cloud synchronization, real-time file watching, and zero-latency local vector indexing for engineers and researchers.

### C. QuickMark (Mobile & Utility)
A minimalist mobile capture and task sequencing application designed to eliminate cognitive friction and context switching on the go.

### D. PromptCraft & TabShield (Productivity Extensions)
- **PromptCraft**: A contextual browser copilot that organizes prompt vaults and injects shortcuts into web interfaces.
- **TabShield**: A smart memory saver that reduces CPU overhead for tab-heavy researchers.

### E. FuseFlow (Cloud Automation Platform)
An event-driven workflow engine that connects relational databases, webhooks, and third-party APIs into resilient background pipelines with built-in retry queues.
